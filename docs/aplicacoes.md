# ELiXX — Aplicações (Fase 08)

Uma aplicação é um programa com telas, tema, estado e dados:

```text
tema escuro { ... }
estado { ... }
dados usuarios { ... }
tela dashboard { ... }
tela usuarios { ... }
```

Exemplos: `navegacao.elixx` (telas), `aplicacao-completa.elixx`
(tema + telas + form + tabela + modal + abas + dados + gráfico),
`crud.elixx` (GET/POST/PUT/DELETE no demo local).

Estado: só global nesta fase (local documentado para Fase 09).
Sem wrapper `aplicação`: o programa já é a aplicação.
